# Renato Costa — Portfólio interativo

Portfólio com visual de terminal e cena 3D em Three.js r180, com núcleo e partículas que reagem ao mouse e ao toque.

## Executar localmente

Sirva a raiz do repositório por HTTP, por exemplo:

```sh
python -m http.server 8000
```

Abra http://localhost:8000. Não abra o HTML diretamente por file://, pois a cena usa módulos JavaScript.

## Recursos

- Terminal: help, about, projects, skills, contact e clear.
- Histórico com setas e preenchimento com Tab.
- Cena 3D com pausa, redução de movimento e ajuste para celular.
- Projetos e contato.

Three.js é distribuído em vendor/ com sua licença MIT. Não há etapa de build.

# Renato M. Costa — Portfólio V2

Portfólio profissional estático em HTML, CSS e JavaScript.

## Publicar no GitHub Pages
1. Substitua os arquivos atuais do repositório por `index.html`, `style.css` e `script.js`.
2. Em Settings > Pages, mantenha `Deploy from a branch`, `main`, `/ (root)`.
3. Aguarde o deploy.
